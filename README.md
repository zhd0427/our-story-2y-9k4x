# our-story-2y-9k4x

一个两周年纪念主题的单页网站，使用原生 HTML、CSS 和 JavaScript 实现，结合照片、文字和音乐展示共同经历。

## 内容与交互

- 纪念日期与相处天数展示。
- 照片、故事和日常记录。
- 音乐播放与页面导航。

## 文件结构

```text
.
├── index.html    # 页面结构、样式、内容和交互逻辑
├── photos/       # 页面使用的照片
├── songs/        # 页面使用的音乐
└── README.md
```

请保持 `index.html` 中的资源路径与实际文件名一致，包括大小写。移动或重命名照片、音乐后，需要同步更新页面引用。

## 本地预览

下载完整仓库后，用浏览器打开 `index.html`。预览时保留 `photos/` 和 `songs/` 的相对位置，无需安装前端依赖或执行构建命令。

如果音乐没有自动播放，请先点击页面上的播放控件；播放行为受浏览器的媒体策略影响。

## GitHub Pages

本仓库已启用 GitHub Pages。发布来源以仓库 **Settings → Pages** 的配置为准。修改后等待部署完成，再检查照片加载、页面切换、日期显示和音乐播放。

## 修改内容

页面文字、纪念日期、照片列表和音乐列表在 `index.html` 中维护，媒体文件分别放在 `photos/` 和 `songs/`。

照片和音乐应使用适合公开分享的内容。公开仓库中的资源可以被直接访问；调整公开范围时，应同时检查仓库与已发布网站。

## 维护检查

- 替换媒体后检查文件名和相对路径。
- 在手机和桌面浏览器查看文字与照片布局。
- 点击播放控件确认音乐可加载。
- 检查纪念日期和时区是否符合预期。
